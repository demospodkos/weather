# Погода

Лёгкое приложение погоды (один HTML-файл, ~6 КБ). Определяет местоположение, показывает текущую погоду и прогноз на 7 дней: температура, ветер, влажность, осадки, давление.

Данные: [Open-Meteo](https://open-meteo.com) (бесплатно, без ключа, CC BY 4.0). Последний прогноз сохраняется и показывается при плохой связи.

- Веб-версия: GitHub Pages (Settings → Pages → ветка `main`, папка `/root`)
- APK: вкладка Actions → Build APK → Run workflow → артефакт `pogoda-apk`
